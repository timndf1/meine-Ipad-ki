Gerät, Offlinebetrieb & Datenschutz

Gerät wird geprüft …

Offline-Vorbereitung läuft …

Modell und Software werden von jsDelivr, Hugging Face und GitHub geladen. Diese Dienste sehen dabei übliche Verbindungsdaten. Dein Chat wird nur in diesem Browser gespeichert. Browserdaten löschen entfernt auch den Verlauf und gegebenenfalls das Modell.

Für den Offline-Test: zuerst eine Antwort erhalten, dann Flugmodus einschalten und die App neu öffnen. Erst wenn das klappt, ist der Offlinebetrieb auf deinem Gerät bestätigt. Safari kann gespeicherte Daten später entfernen.

Das kleine Modell kann sich irren und ist bei schwierigen Aufgaben begrenzt. Es durchsucht nicht das Internet.
